# Macro micromorphic problem with a dummy material

A single-scale micromorphic macro problem using `DummyMicromorphicMaterial`
(a linear, decoupled constitutive law) with a single micromorphic mode — useful
for verifying the mixed `(u, v)` formulation without a nested RVE.

## Run

```bash
python run_macro_micromorphic.py
```
